# anpho's Windows Explorer Extension 

## About Artifacts

Artifacts | Description
--- | ---
ExplorerExtensionSetup.exe | Installer for Windows Explorer Extension
Extensions-x86-0.01.zip | 32-bit version of Windows Explorer Extension
Extensions-x64-0.01.zip | 64-bit version of Windows Explorer Extension

## How to install

Download ExplorerExtensionSetup.exe and run.

OR

Download zip file and extract, then use `regsvr32` to register the DLL.
